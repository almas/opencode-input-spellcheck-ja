# opencode-input-spellcheck-ja

入力欄の日本語を完全オフラインでチェックするプラグイン。同梱の JMdict 辞書（共通語彙）と
照合するため、**実行中にネットワークへアクセスすることは一切ありません**。

## 何をする？

プロンプト入力欄（Composer）などで単語を選択して**右クリック**すると、辞書にない語のときだけ
小さなメニューが出て、確実な修正だけを提案します。

- **ローマ字のまま入力した語の変換**: `sikaka` → 「しかく」、`sensei` → 「せんせい」
- **かなの一文字違いの誤入力修正**: 辞書に実在する「編集距離1」の語だけを表示（か↔が などの濁点、撥字、1画多い/少ないかな）
- 候補をクリックすると `execCommand("insertText")` 経由で置換されるので、Composer のチップ（@ファイル参照など）や履歴はそのまま保たれます

**誤検知ゼロ設計**: 置換候補が1つも出てこない語にはメニューすら表示せず、通常の右クリックメニュー
（カット/コピー等）をそのまま通します。英語ワード・識別子・ファイル名には干渉しません。

## しないこと

- エディタ風の自動下線（スクイグルー）や自動変換は行いません。必ず「選んで右クリック」したときだけ動きます
- メッセージ本文の右クリックは `opencode-dictionary`（辞書プラグイン）が担当します

## 必要環境

- OpenCode Desktop（またはサーバー）。追加のインストール不要

## インストール

`~/.config/opencode/opencode.jsonc` の `plugin` 配列に追記し、`/reload` します。

```jsonc
{
  "plugin": [
    "file:///絶対パス/opencode-input-spellcheck-ja"
  ]
}
```

## 使い方

1. 入力欄で怪しい語をダブルクリック等で選択
2. 右クリック → 出てきた候補をクリックで置換
3. 終わり

## データの更新

`npm run fetch-data`（開発時のみネットワークを使用）。出典とライセンスは [DATA.md](./DATA.md)。
